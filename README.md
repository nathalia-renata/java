# ☕ Java: Programação Orientada a Objetos e Projetos

## 📝 Descrição

Este repositório reúne minhas atividades, exercícios e projetos desenvolvidos em Java. Ele documenta a evolução dos meus estudos na linguagem, com foco em Programação Orientada a Objetos (POO), boas práticas de desenvolvimento e resolução de problemas estruturados.

## 🚀 Conteúdos e Tópicos Abordados

- **Fundamentos da Linguagem:** Sintaxe, tipos primitivos, operadores, estruturas condicionais e laços de repetição.
- **Programação Orientada a Objetos (POO):** 
  - Classes, objetos, atributos e métodos.
  - Abstração, Encapsulamento, Herança e Polimorfismo.
  - Interfaces, classes abstratas e enumerações (`enums`).
- **Coleções (Collections Framework):** Manipulação de listas, conjuntos e mapas (`List`, `ArrayList`, `Set`, `Map`).
- **Tratamento de Exceções:** Uso de blocos `try-catch`, `finally` e criação de exceções personalizadas.
- **Entrada e Saída de Dados (I/O):** Leitura, escrita e manipulação de arquivos de texto.
- **Lógica e Estruturas de Dados:** Implementação de algoritmos práticos, manipulação de vetores e matrizes.
